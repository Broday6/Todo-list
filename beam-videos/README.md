# Beam Studio — code-only motion graphics

Three videos about **faux wood beams**, one for each of the video formats in the marketing guidelines. Every pixel and every sound is generated by the code in this folder. There's no stock footage, no image or video generator, and no editing app. The wood grain, rooms, lighting, icons, host character, type animation and music are all procedural.

| File | Format | Length | Notes |
|---|---|---|---|
| `out/CAV_Faux-Wood-Beams.mp4` | C.A.V. (category ad video) | 0:40 | Main cut, with a review slot |
| `out/CAV_Faux-Wood-Beams_No-Reviews.mp4` | C.A.V. | 0:40 | Amazon-safe version: the review slot is replaced by a benefit card |
| `out/CEV_Faux-Wood-Beams.mp4` | C.E.V. (category explainer video) | 2:41 | Host script shown as captions; A-roll plates mark the talking-head cuts |
| `out/MOV_Polyurethane.mp4` | M.O.V. (material overview video) | 2:12 | Voice-over script shown as captions; material limitations are shown on screen, not said |

All videos are 1920×1080, 30 fps, H.264 High profile with AAC 256k audio.

## How each video follows its guideline

**C.A.V.** is cut to a 120 BPM grid, 40 s, which is under Amazon's 45 s limit. The sections run in guideline order:
1. 3 close-up detail shots.
2. "Featuring Faux Wood Beams" title.
3. 3 finished rooms: great room, vaulted, coffered.
4. 3 titled install steps.
5. Designs, colors, sizes, creative uses (mantels) and a unique feature (lightweight).
6. The review slot.
7. The Ekena logo.

The video contains no prices and no star ratings outside the review slot.

**C.E.V.** follows all 12 guideline elements in order:
1. Logo intro.
2. What the category is.
3. Why you'd want it: adds value (before/after slider), trendy (3 looks), hides mistakes, can be removed later.
4. Options: textures, sizes, finishes.
5. Material and why.
6. How it's made.
7. 4-step installation.
8. How it's different (vs. solid timber).
9. Complementary products.
10. Other products.
11. Call to action.
12. Logo, phone and website.

**M.O.V.** covers polyurethane in guideline order:
1. Hype intro of products made from it.
2. Voice-over intro ("especially perfect for projects that…").
3. The material in application.
4. Every benefit: lightweight, moisture, insects, detail, stability, workability.
5. The products we make from it.
6. How it's made.
7. Finishes.
8. General installation.
9. Recap.
10. "If this material doesn't sound like it's for you…"
11. Logo, phone and website.

The limitations are **shown, not said**, following the guideline's carved-PVC example:
- The hollow U-channel profile is visible.
- Beams mount on blocks, which makes it clear they're decorative, not structural.
- The saw cut reveals the foam core.

## Placeholders to replace before publishing

- **Logo:** the "E" built from beams plus the "EKENA MILLWORK" wordmark is a stand-in. Swap in the real logo animation (`logoLockup` in `src/gfx.js`).
- **Phone number:** `(000) 000-0000` (`BRAND.phone` in `src/gfx.js`).
- **Review:** the C.A.V. main cut has a clearly marked review placeholder. Paste a real customer review in `src/cav.js`, or use the No-Reviews version.
- **Voice / host:** the C.E.V. uses an illustrated host and the M.O.V. uses captions in place of recorded audio. Treat both as a timed animatic, or burn in the real A-roll and VO.
- **Product and finish names:** texture names (Hand Hewn, Rough Sawn, Sandblasted, Smooth) and finish names are generic. Check them against the live catalog, along with the product lists (straps, corbels, mantels, medallions, domes) and the claims (moisture-resistant, insect-proof), before publishing.

## Rendering

Requirements: Node 18+ with Playwright (Chromium), Python 3 with `numpy` and `imageio-ffmpeg` (which ships an ffmpeg binary used only to encode).

```bash
node render.mjs cav                   # C.A.V. main
node render.mjs cav noreviews         # C.A.V. Amazon-safe
node render.mjs cev
node render.mjs mov
node render.mjs cev --still 12,40.5 --list 1   # review single frames + print shot list
```

`./deliver.sh out/<file>.mp4` makes a sub-28 MB copy (`*_share.mp4`) for chat or email; the masters are high-bitrate for editing and upload.

The renderer opens `src/index.html` in headless Chromium, steps the timeline one frame at a time, and pipes the PNG frames into ffmpeg across 4 parallel workers. It then runs `audio.py` to synthesise the soundtrack and muxes the result.

## Code map

| File | What's inside |
|---|---|
| `src/core.js` | Easing, seeded RNG, value noise and fbm, **procedural wood** (4 textures × 6 finishes with relief shading, adze facets, saw marks, checks, knots), a small **3D renderer** (perspective camera, near-plane clipping, perspective-subdivided texture mapping, painter's sort, point and sun lighting with tone mapping, smooth-shaded planes), text and path helpers, film grain and vignette |
| `src/sets.js` | Procedural rooms: great room, coffered ceiling, vaulted ceiling with rafters, fireplace with beam mantel |
| `src/gfx.js` | Brand pieces, captions, lower thirds, 20+ line icons, 2D product renders, install cross-section, host character, medallion, corbel, strap, crown moulding, balance scale, water droplets, termites, magnifier, warping-wood demo, saw blade, paint roller, casting process, comparison table, transitions (beam wipe, push, flash, zoom, fade) |
| `src/cav.js`, `src/cev.js`, `src/mov.js` | The three timelines (shots, captions and transitions) |
| `audio.py` | Numpy synth: kick, snare, hats, bass, pads, plucks, risers, whooshes and convolution reverb. The C.A.V. track hits on the cut points; C.E.V. and M.O.V. get a quieter bed that sits under a voice-over |
| `render.mjs` | Frame renderer, parallel encoder and muxer |
